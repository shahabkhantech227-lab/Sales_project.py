# Sales Data Analysis with Python, Pandas, and Matplotlib

## Project Overview

This project explores a sales dataset using Python. It covers data cleaning, summary statistics, sales analysis, and charts to make the results easier to understand.

The project was completed as hands-on practice with Pandas and Matplotlib in VS Code.

## Project Goals

- Load and inspect the sales dataset.
- Check for missing values and duplicate records.
- Clean the data and prepare it for analysis.
- Review sales, profit, and quantity.
- Compare results by product and region.
- Explore sales by month.
- Create charts to present the findings.

## Tools and Libraries

- Python
- Pandas
- Matplotlib
- Visual Studio Code

## Data Preparation

The data preparation steps include checking missing values, identifying and removing duplicate rows, and converting date values where needed. The cleaned data is then used for the analysis.

## Analysis

The project includes:

- Total sales, profit, and quantity
- Product-wise sales and profit
- Region-wise sales and profit
- Monthly sales analysis

## Setup

### 1. Install the required libraries

Open the VS Code terminal and run:

```bash
pip install pandas matplotlib
```

### 2. Check the dataset path

Make sure the dataset is in the location expected by `sales.py`. If your code uses a different file name or folder, update this step accordingly.

### 3. Run the project

From the project folder, run:

```bash
python sales.py
```
